# Mrkh97's Homebrew tap

## Mochi

A cat that lives on your Mac desktop. She walks on your windows, hides behind them, naps on them and expects to be fed. See the [project page](https://github.com/Mrkh97/mochi) for what she does.

```sh
brew install --cask mrkh97/tap/mochi-cat
```

Then open Mochi from your Applications folder and look for the cat face in the menu bar.

| | |
|---|---|
| Update | `brew upgrade --cask mochi-cat` |
| Uninstall | `brew uninstall --cask mochi-cat` |
| Uninstall and forget her settings | `brew uninstall --cask --zap mochi-cat` |

If you installed Mochi by hand before, add `--force` the first time so Homebrew can replace that copy.

Needs macOS 14 Sonoma or later, on Apple silicon or Intel.

### Notes

- The cask is called `mochi-cat` because `mochi` in Homebrew is an unrelated flashcards app.
- Mochi is signed with a Developer ID and notarized by Apple, so it opens like any other downloaded app.
- The cask is updated automatically whenever a new Mochi release is published.

## Light Key

A tiny lightning bolt strikes every character you type, anywhere on your Mac, and the word you're typing gets electrocuted. See the [project page](https://github.com/Mrkh97/light-key) for how it works.

```sh
brew install --cask mrkh97/tap/light-key
```

Then open Light Key from your Applications folder, allow Accessibility when macOS asks, and look for ⚡ in the menu bar.

| | |
|---|---|
| Update | `brew upgrade --cask light-key` |
| Uninstall | `brew uninstall --cask light-key` |
| Uninstall and forget its settings | `brew uninstall --cask --zap light-key` |

If you installed Light Key by hand before, add `--force` the first time so Homebrew can replace that copy.

Needs macOS 14 Sonoma or later, on Apple silicon or Intel. Light Key is signed with a Developer ID and notarized by Apple, and the cask is updated automatically whenever a new release is published.

## LightTrail

Your mouse leaves a trail of crackling lightning that fades away in under half a second, with forked bolts, sparks and nine colors. See the [project page](https://github.com/Mrkh97/light-trail) for what it does.

```sh
brew install --cask mrkh97/tap/lighttrail
```

Then open LightTrail from your Applications folder, move your mouse, and look for the bolt in the menu bar.

| | |
|---|---|
| Update | `brew upgrade --cask lighttrail` |
| Uninstall | `brew uninstall --cask lighttrail` |
| Uninstall and forget its settings | `brew uninstall --cask --zap lighttrail` |

If you installed LightTrail by hand before, add `--force` the first time so Homebrew can replace that copy.

Needs macOS 13 Ventura or later, on Apple silicon or Intel. LightTrail is signed with a Developer ID and notarized by Apple, and the cask is updated automatically whenever a new release is published.
